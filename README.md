# Кости — У тракта

Офлайн-игра для Android по правилам костей Kingdom Come: Deliverance II.
Самостоятельная реализация: таверна при свечах, объёмные анимированные кости,
русский интерфейс, ИИ и два игрока за одним телефоном.

## Что работает

- Шесть костей, выбор комбинаций, зачёт, переброс оставшихся, сгорание очков хода.
- Полный повторный бросок, когда зачтены все кости; победа только при зачёте.
- Одиночные 1/5, тройки, последовательности и удвоение за дополнительные одинаковые кости.
- 43 вида костей с отдельными вероятностями; джокер дьявола и выбор грани Шута.
- 34 бляхи: перебросы, превращение, сила, воскрешение, защита, множители и формации.
- Четыре ИИ с разными наборами костей и склонностью к риску; ИИ не подменяет броски.
- Два отдельных набора для игры вдвоём, восемь столов, игровые ставки и свободная игра.
- Автосохранение, журнал, подсказки, звук, вибрация, портретный и альбомный интерфейс.
- Объёмный WebGL-стол: скруглённые кости, отскоки, столкновения, контактные тени и зачёт с перемещением к краю стола.
- Никаких аккаунтов, рекламы, покупок и сетевых разрешений в Android-приложении.

## Статус точности

Версия **0.1.0** — играбельная реализация, **не подтверждённая копия 1:1**.
Базовые правила сверены по открытым справочникам. Численные эффекты некоторых блях,
поведение добавленной кости и часть вероятностей требуют проверки непосредственно в KCD2.
Список расхождений и допущений — [docs/PARITY.md](docs/PARITY.md).
Оформление и фон созданы заново; оригинальные модели, музыка и интерфейс игры не включены.

## Запуск в браузере

Для запуска нужен Python 3. Для тестов — Node.js 22+ и jsdom (dev-зависимость).
Three.js включён в исходники и APK; установка npm-зависимостей для самого приложения не нужна.

```bash
npm ci
npm test
npm run serve
```

Откройте `http://localhost:8080`. Не открывайте HTML через `file://`: приложение использует ES-модули.

## Android

Android 8.0+ и актуальный Android System WebView. APK универсален для архитектур,
поскольку не включает нативные библиотеки. Минимальный Java WebView загружает
все файлы из APK через локальный HTTPS origin, без обращения в интернет.

Для сборки нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0:

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
bash scripts/build-android.sh
```

Результат: `build/Kosti-u-trakta.apk`. Подпись проверяется сборочным скриптом.
По умолчанию создаётся development-ключ; для последующих обновлений используйте тот же ключ:

```bash
export DICE_KEYSTORE=/private/path/dice.jks
export DICE_STORE_PASSWORD=your-password
export DICE_KEY_PASSWORD=your-password
bash scripts/build-android.sh
```

Приватный ключ не хранится в репозитории. Ключи разных сборок несовместимы для установки обновления поверх.
GitHub Actions проверяет механику и собирает development APK как downloadable artifact.

## Файлы

- `web/engine.js` — правила, машина состояний, ИИ и сохранения.
- `web/data.js` — кости, вероятности, бляхи и столы.
- `web/table-scene.js` — WebGL-сцена, материалы костей, тени и выбор касанием.
- `web/table-motion.js` — визуальная модель движения; результаты определяет игровой движок.
- `web/renderer.js` — выбор WebGL или резервного Canvas-рендерера, миниатюры костей.
- `web/ui.js`, `web/style.css` — меню и игровой интерфейс.
- `android/` — Android-оболочка без сторонних зависимостей.
- `tests/` — проверки комбинаций, переходов хода, блях и завершения 300 партий.

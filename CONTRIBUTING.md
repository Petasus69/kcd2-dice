# Дальнейшая разработка

Основной проект — Godot 4.6.3 в `godot/`, основная ветка — `main`.
Для отдельной доработки создавайте ветку от актуального `main` и оформляйте
pull request с описанием поведения и выполненных проверок.

- Игровые функции, интерфейс и физику меняйте в `godot/`.
- `legacy/` сохраняется как архив и эталон правил. Перенос путей или исправление
  документации допустимы; изменения эталонной логики требуют отдельного объяснения.
- Следите за состоянием сохранений и совместимостью Android-пакета.
- Для правил выполняйте сверку с эталоном; для бросков и блях — физические
  проверки; для интерфейса — мобильные проверки и визуальную оценку.
- Касания и производительность дополнительно проверяйте на телефоне,
  указывая модель устройства и версию Android в отчёте.
- Сохраняйте `.gd.uid` и настройки импорта ресурсов в Git. Кэш `.godot/`,
  APK, приватные ключи и локальные пароли в Git не включаются.
- GDScript: четыре пробела, UTF-8, окончания строк LF. Избегайте добавления
  новых зависимостей, если задачу можно решить средствами Godot.

Команды, устройство проекта и подпись APK описаны в
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
О проблеме сообщайте с шагами воспроизведения, версией приложения,
ожидаемым результатом и скриншотом либо записью, если это помогает понять поведение.

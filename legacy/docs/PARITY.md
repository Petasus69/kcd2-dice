# Сверка с KCD2

Цель: приблизиться к полной механической и визуальной совместимости мини-игры.
Эта сборка не должна описываться как точная копия до проверки спорных случаев в оригинале.

## Проверенные базовые правила

| Правило | Реализация |
| --- | --- |
| Шесть костей, поочерёдные ходы | Есть |
| Единица 100, пятёрка 50 | Есть |
| Тройка единиц 1000; остальные тройки = число × 100 | Есть |
| Каждая дополнительная одинаковая кость удваивает тройку | Есть |
| 1–5 = 500; 2–6 = 750; 1–6 = 1500 | Есть |
| Каждая выбранная кость обязана давать очки | Есть |
| Очки из разных бросков не объединяются в тройки | Есть |
| Пустой бросок сжигает только текущий ход | Есть |
| Если все кости зачтены, бросаются снова все шесть | Есть |
| Победа после добровольного зачёта, без последнего ответа противника | Есть |
| Нет отдельного бонуса за три пары или полный дом | Есть |

## Реализовано, но требует сверки непосредственно в игре

1. **Фора:** 100/200/400 для олова/серебра/золота — предварительные числа.
2. **Рез/Виселица/Око:** 200/300/300 — предварительные числа. Паттерны 3+5, 4+5+6, 1+3+5 подтверждены.
3. **Сила:** дополнительная обычная кость остаётся доступной при hot dice до окончания хода.
   Тип добавляемой кости и момент её удаления нужно проверить.
4. **Защита:** в этой реализации пассивно подавляет бляху такого же ранга на всю партию.
   Нужно проверить момент активации и взаимодействие с уже использованными эффектами оригинала.
5. **Император/Тихе:** множитель применяется также к группам из 4+ костей.
6. **Дьявол:** символ заменяет число в группе от трёх или в последовательности, не одиночную 1/5.
   Все комбинации с несколькими дьяволами требуют проверки в KCD2.
7. **Шут:** вероятность символа — 1/6, заменяет единицу. Другие грани равновероятны.
   Точные вероятности коллаборационной кости требуют проверки.
8. **Вероятности:** использована таблица INARA; у Fandom есть расходящиеся числа
   для Lu/Ci/Fer, Holy Trinity и некоторых других костей. Частоты не сверены с файлами версии игры.
9. **Ставки и столы:** безбляховые цели 1500/2000/3000/4000.
   Вместо полного списка названий бляховых контрактов используются четыре самостоятельных стола;
   цели для них заданы проектом. ИИ, экономика и доступность всей коллекции тоже самостоятельные.
10. **Полнота каталога:** 43 кости и 34 бляхи, включая DLC/Шута; не подтверждено,
    что каталог полностью совпадает с установленной версией KCD2.

## Визуальные отличия

Фон — самостоятельно созданная таверна. Кубики программно проецируются из трёхмерной
геометрии в Canvas, имеют шесть граней, оттенки, тени и вращение. Это не полноценная
сцена KCD2: нет оригинальных NPC, рук, моделей, озвучки и физики контакта кубиков.
Бросок визуально анимируется после определения честного результата движком;
анимация не участвует в генерации случайных чисел.

## Проверка релиза

- 20 автоматических тестов, включая 300 детерминированных завершённых партий движка и проверку обработчиков интерфейса через jsdom.
- Реальный визуальный просмотр в Chromium в этой среде не выполнен: запуск браузера блокируется на создании socket. Вёрстка и обработчики проверены раздельно; визуальная проверка на устройстве остаётся.
- APK собирается Android Build Tools, подпись проверяется apksigner.
- Установка и запуск на физическом Android пока не проверены.
